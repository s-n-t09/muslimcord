MuslimCord

This page explains how to install MuslimCord. Copy this URL into Discord → Settings → Plugins:

https://s-n-t09.github.io/muslimcord/MuslimCord/
  1. Open Discord, then Settings, then Plugins.
  2. Press +.
  3. Paste the URL and press Install.
  4. Press Confirm if requested.
  5. Use the 🔧 button next to MuslimCord to configure location, reminders, sound, and language.
