MuslimCord

تذكيرات هادئة بأوقات الصلاة والدعاء والصلاة على النبي ﷺ داخل تطبيقات Discord المتوافقة مع Vendetta وRevenge وKettu.

Gentle prayer-time, du'a, salawat, and adhan reminders for Vendetta-compatible Discord clients, including Revenge and Kettu.

رابط التثبيت

انسخ الرابط التالي والصقه في صفحة Plugins داخل Discord:

https://s-n-t09.github.io/muslimcord/

المزايا

كل صوت أذان متاح له نسختان موثقتان: أذان عادي وأذان فجر، مع تنزيل محلي يدعمه عميل Discord المتوافق. تعرض نافذة التنزيل النسبة والحجم والسرعة والوقت التقريبي المتبقي وتتيح الإلغاء.

طريقة التثبيت

  1. انسخ رابط التثبيت الظاهر أعلاه.
  2. افتح Discord ثم اذهب إلى Settings ثم Plugins.
  3. اضغط على علامة + لبدء إضافة Plugin.
  4. الصق الرابط واضغط Install.
  5. إذا ظهر طلب تأكيد، اضغط Confirm.
  6. اضبط تفضيلاتك من زر الإعدادات 🔧 بجانب اسم MuslimCord.

Installation

Copy the installation URL below and paste it into Discord → Settings → Plugins.

https://s-n-t09.github.io/muslimcord/
  1. Copy the installation link above.
  2. Open Discord and go to Settings, then Plugins.
  3. Press the + button to add a plugin.
  4. Paste the link and press Install.
  5. If a confirmation appears, press Confirm.
  6. Open the 🔧 button next to MuslimCord to configure your preferences.

Features

Choose a location, refresh prayer times, set du'a reminders from 30 minutes to three hours or a custom interval, set salawat reminders with the requested three-minute delay, choose a simple notification sound or a selectable full adhan voice with separate regular and Fajr files, view a cancellable download modal with percentage, size, speed, and estimated time remaining, and switch between Arabic and English.

Every available adhan voice has both a regular version and a Fajr version. Voices without a verified pair are not shown. Local audio tests use only a supported file URI; if the Discord client does not expose a compatible local-file API, the action fails safely instead of passing a data URI to native playback.
